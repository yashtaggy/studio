# **App Name**: Yashflix Portfolio

## Core Features:

- Navbar: Displays a navigation bar with a logo ('Yashflix') and menu items: Projects, Skills, Experience, Contact.
- Hero Banner: Full-screen banner with a dark gradient, headline, subtitle, and buttons linking to resume and GitHub.
- Projects Section: Displays projects in Netflix-style rows with hover cards, including project descriptions and GitHub links.
- Skills Section: Displays skills as Netflix genre-style categories.
- Certifications Section: Lists certifications and achievements.
- Experience Section: Details professional experience with roles and responsibilities.
- Footer: Presents contact information and links to social media profiles.

## Style Guidelines:

- Primary color: Dark red (#E50914) to capture the essence of Netflix's bold branding.
- Background color: Very dark gray (#141414) to emulate Netflix's dark UI, nearly black. 
- Accent color: Light gray (#E5E5E5) to provide contrast for text and interactive elements.
- Body and headline font: 'Inter', a sans-serif font providing a modern and neutral aesthetic suitable for both headings and body text.
- Use React Icons for social and GitHub links.  Maintain a consistent size and style to ensure visual coherence.
- Implement a responsive layout that adapts to desktop and mobile screens, ensuring optimal viewing experience across devices.
- Utilize Framer Motion for fade-in effects, hover animations on project cards, and smooth transitions throughout the site.
